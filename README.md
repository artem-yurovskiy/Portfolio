# Artem Yurovskiy — Portfolio

My personal portfolio site, built to showcase my projects, experience, and skills.

**Live site:** [artem-yurovskiy.com](https://artem-yurovskiy.com)

## Tech Stack

- **React** — component-based UI
- **Vite** — build tooling and dev server
- **Tailwind CSS** — styling and custom dark theme
- **Vercel** — hosting and deployment

## Running Locally

```bash
npm install
npm run dev
```
